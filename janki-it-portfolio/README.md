# Janki Luitel — IT Portfolio

Recruiter-facing portfolio built with React + Vite.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Build

```bash
npm run build
```

## Before publishing

1. Put your latest resume in `public/Janki_Luitel_Resume.pdf`
2. Confirm the GitHub profile URL in `src/App.jsx`
3. Add screenshots and project-specific GitHub links as projects are polished
4. Replace the Data Analytics placeholder once the project is ready

## Recommended free deployment

- GitHub Pages
- Netlify
- Vercel
- Cloudflare Pages

## Structure

- `src/App.jsx` — portfolio content
- `src/styles.css` — design
- `public/` — resume and future images
